# 示例演示资料品牌统一与内容扩充设计

## 目标

将 `需要的例子演示/` 中的六份资料统一为“启元智匣科技有限公司”品牌体系，并增加适用于企业知识库演示的流程与技术内容。保留现有资料主题、文档编号和核心结构，不触及 GenBox-Agent 的项目名称、代码包名、数据库标识或运行配置。

## 品牌口径

- 公司全称统一为：启元智匣科技有限公司。
- 旧公司、旧平台、旧门户、旧培训系统、旧客服平台、旧邮箱域名、旧支持邮箱与产品归属统一换成“启元智匣”体系。
- 文件名中的旧公司或平台名称同步更新；产品型号 `XX-200` 更名为 `QY-200`，并更新 PDF 的标题、元数据、正文、页脚和技术支持邮箱。
- 不把 `GenBox-Agent`、`com.genbox`、`genbox_agent` 等项目技术标识视为品牌露出，不作替换。

## 内容质量规则

- 每份 Markdown 文档至少新增一个可供问答检索的“典型场景”或“核对清单”区块，覆盖角色、输入、步骤、产出、时限或验收条件。
- 制度类资料强调审批边界、留痕和例外处置；技术类资料强调前置检查、可观测指标、恢复验证与复盘。
- 虚构的人名、电话和业务数据保持为演示信息，避免声称是真实联系渠道。
- PDF 重建后必须完成文本提取检查和全部页面的渲染检查，确保没有错字、溢出、重叠或乱码。

## 验收标准

1. `需要的例子演示/` 中不再出现旧公司名称、旧邮箱域名、`XX-200` 或旧公司归属。
2. 文件名、正文、PDF 元数据和 PDF 页脚的品牌口径一致。
3. 六份资料均含有品牌统一后的内容；五份 Markdown 文档均增加实质性业务或技术演示内容。
4. PDF 可以正常打开，六页均排版完整、文本可读且支持渠道一致。
